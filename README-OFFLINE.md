# ڕێبەری بەکارهێنانی سیستەمی ئۆفلاین (100% Offline Windows POS)
## سەنگەر زمارەیی و جێگر زمارەیی - بۆ فرۆشتنی پارچەی بارهەڵگر

ئەم پرۆژەیە گۆڕدراوە بۆ سیستەمێکی تەواو **ئۆفلاین (Offline)** کە لەسەر کۆمپیوتەر و لاپتۆپی ویندۆز بەبێ پێویستی بە هیچ هێڵێکی ئینتەرنێت، بەبێ کۆمپانیای دەرەکی (No Supabase, No Vercel, No Gemini)، کار دەکات.

---

## ١. چۆنیەتی دەستپێکردن بە یەک کرتە (One-Click Launch)

لەناو فۆڵدەری پرۆژەکەدا:
1. دوو کرتە (Double Click) لەسەر فایلی:
   `Start Sangar POS.bat` (یان `Start Sangar POS.vbs` بۆ دۆخی بێدەنگ) بکە.
2. سیستەم خۆکارانە بنکەی زانیاری دەخاتە کار و وێبگەڕەکەت (Chrome یان Edge) دەکاتەوە لەسەر:
   `http://localhost:3000`

## ٣. بنکەی زانیاری و شوێنی پاراستنی داتا (Database Location)

- بنکەی زانیاری سەرەکی:
  `data/shop.db` (SQLite بە بزوێنەری خێرای WAL و Foreign Keys چالاککراو)
- فۆڵدەری باکئەپ:
  `backups/`
- فۆڵدەری لۆگ و تۆمارەکان:
  `logs/`

---

## ٤. دروستکردن و گەڕاندنەوەی باکئەپ (Database Backup & Restore)

1. لە بەشی **ڕێکخستنەکان (Settings)** یان لە ڕێگەی API:
   - بەڕێوەبەر دەتوانێت باکئەپ دروستبکات بە یەک کرتە.
   - فایلی باکئەپ لە فۆڵدەری `backups/shop-backup-YYYY-MM-DD_HH-mm-ss.db` بە سەلامەتی پاشەکەوت دەبێت.
2. دەتوانیت لە هەر کاتێکدا کۆپییەکی تەواوی فۆڵدەری `data/shop.db` یان `backups/` بخەیتە سەر فلاش مۆمۆری (USB Flash Drive).

---

## ٥. ئامادەکاری بۆ لاپتۆپی تر لەسەر تۆڕی ناوخۆیی (LAN Ready)

سێرڤەرەکە بە شێوازی `0.0.0.0:3000` ڕێکخراوە. ئەگەر لە داهاتوودا بتەوێت لە لاپتۆپ یان تابلێتێکی تر لەسەر هەمان مۆدێم/وایفای (LAN) فرۆشتن بکەیت:
1. لە لاپتۆپی سەرەکی، فەرمانی `ipconfig` لێبدە بۆ دۆزینەوەی IP ناوخۆیی (بۆ نموونە: `192.168.1.50`).
2. لە لاپتۆپی دووەمدا، لە وێبگەڕ بنووسە:
   `http://192.168.1.50:3000`

---

## ٦. تەکنەلۆژیا و بزوێنەری سیستەم

- **بەرگی پێشەوە (Frontend):** HTML5 / CSS3 (RTL / Kurdish Sorani) / Vanilla JavaScript
- **سێرڤەر (Backend):** Node.js + Express (Port 3000)
- **بنکەی زانیاری (Database):** SQLite (`data/shop.db`) with `PRAGMA journal_mode = WAL`, `PRAGMA foreign_keys = ON`, `PRAGMA busy_timeout = 5000`
- **ئاسایش و وشەی نهێنی:** Bcrypt + JSON Web Token (JWT)
- **چاپکردن:** پسووڵەی گەرمیی 80mm و پسووڵەی فەرمیی A4
- **هەژماری بازرگانی:** فرۆشتنی نەقد و قەرز، سیستەمی FIFO، کۆمپانیاکان و شۆفێر و ژمارەی ئۆتۆمبێل، قاسە و جموجۆڵی دارایی.
